# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft-foundry/microsoft-ai-samples/issues) to track bugs and feature requests for the samples in this repository. Please search existing issues before filing a new one to avoid duplicates.

For sample bugs, include the sample path, the steps to reproduce the issue, your runtime and dependency versions, and any relevant error messages. Do not include credentials, secrets, or sensitive data in issues, logs, or notebook outputs.

**Do not report security vulnerabilities through GitHub Issues.** Follow the private reporting instructions in [SECURITY.md](SECURITY.md).

For help and questions about using these samples:

- Start with the README and setup instructions for the specific sample or workshop.
- For Microsoft Foundry-based samples, consult the [Microsoft Foundry documentation](https://learn.microsoft.com/azure/ai-foundry/).
- For model endpoint access, billing, quotas, or service availability, use the documentation and support channels for your configured endpoint provider.

## Microsoft Support Policy

Support for this **sample repository** is limited to the resources listed above. The samples are provided as-is for learning and reference purposes; they are not covered by formal Microsoft Customer Service & Support (CSS) agreements.
